# CHANGELOG

## 1.0.0 (2024-06-01)

### Initial Release

- **writespace**: Distraction-free writing platform built with React, Vite, and Tailwind CSS.
- **Features:**
  - User authentication (demo, LocalStorage)
  - Admin dashboard & user management
  - Create, edit, delete blog posts
  - Responsive design
  - Role-based access (admin, user, editor)
  - No backend required (demo only)
  - Data persistence via LocalStorage
  - Minimal, clean interface
  - PropTypes for runtime validation
  - ESLint for linting
- **Setup:**
  - `npm install` for dependencies
  - `npm run dev` for development server
  - `npm run build` for production build
- **Demo Admin Login:**
  - Username: `admin`
  - Password: `admin123`
- **Folder Structure:**
  - `src/components/` for UI components
  - `src/pages/` for route/page components
  - `src/utils/` for utility functions
  - `src/App.jsx` for main app routing
  - `src/main.jsx` for entry point
  - `src/index.css` for Tailwind styles
